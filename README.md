# tomsworkers.io

주식회사 톰즈워커즈 회사 소개 한 장입니다. GitHub Pages 로 게시됩니다.

> **Build software that sails.**

- https://tomsworkers.io

## 왜 저장소가 따로인가

**GitHub Pages 는 저장소 하나에 커스텀 도메인 하나다.** 마이베이스볼스타
사이트(`tomsworkers-io/mabas-site`)의 `CNAME` 은 `mybaseballstar.app` 이라,
거기에 `tomsworkers.io` 를 얹으면 앱 주소가 떨어져 나간다. 그 주소는 App
Store 에 제출돼 있고 앱에 상수로 박혀 있어서 끊기면 안 된다.

## 짜임

Jekyll 을 쓰지 않는다(`.nojekyll`). 페이지가 `index.html` 하나뿐인데 레이아웃과
설정 파일을 두면 고칠 곳만 늘어난다. CSS 도 그 파일 안에 있다.

| 파일 | |
|---|---|
| `index.html` | 페이지 전부 (CSS 포함) |
| `CNAME` | 커스텀 도메인 |
| `.nojekyll` | 빌드 없이 그대로 게시 |
| `logo-mark.png` · `logo-mark-dark.png` | 맨 위 줄의 회사 마크 |
| `favicon.png` · `favicon-16.png` | 브라우저 탭 |
| `og-image.png` | 링크 공유 미리보기 |
| `logo.png` | 마이베이스볼스타 아이콘 — 제품 카드 안에서만 |

### 그림에 얽힌 규칙

⚠️ **`logo.png` 는 앱의 아이콘이지 회사 마크가 아니다.** 제품 카드 안에서만
쓴다. 회사 자리에 앱 아이콘을 놓으면 회사와 앱이 같은 것이 된다. 원본은
`mabas-site` 에도 있으므로 갈아 끼울 때 양쪽을 같이 고쳐야 한다.

⚠️ **파비콘은 회사 마크를 줄인 것이 아니다.** 마크를 그대로 16px 로 줄이면
깃발·`</>`·파도가 전부 뭉개져 파란 얼룩 하나만 남는다. 실제로 줄여서 확인했다.
그래서 `TW` 부분만 잘라 키우고, 남색 바탕을 깔아 흰색으로 팠다. 바탕을 까는
이유는 어두운 탭에서 남색 마크가 배경에 묻혀 사라지기 때문이다.

⚠️ **맨 위 줄 마크는 두 벌이다.** 같은 이유로 다크 모드에서 남색이 검은
바탕에 묻힌다. `prefers-color-scheme` 으로 갈아 끼운다.

**로고를 새로 뽑으면 위 다섯 파일을 한꺼번에 다시 만들어야 한다.** 하나만
바꾸면 탭과 머리말과 공유 미리보기가 서로 다른 그림을 말하게 된다.

### 색

강조색은 마크의 파랑이지만 **로고 원색(`#0076F6`)이 아니다.** 그 값은 흰
바탕에서 4.27:1 이라 본문 링크 기준(4.5:1)에 못 미친다. 눈에 거의 같으면서
통과하는 `#0A63D8`(5.54:1)로 내렸다. 다크는 `#4DA3FF`(7.45:1). 색을 손볼 때
이 선을 다시 넘기지 않는다.

마이베이스볼스타의 빨강은 여기 쓰지 않는다. 빨강은 앱 것이다.

## 주소

`CNAME` 이 `tomsworkers.io` 를 정한다. DNS 는 GoDaddy 에 있다. 루트 도메인이라
CNAME 레코드를 쓸 수 없고 A 레코드로 GitHub Pages 를 가리킨다.

| 형식 | 이름 | 값 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `tomsworkers-io.github.io` |

저장소 Settings > Pages 에서 Source 를 `main` 브랜치로 두고, Custom domain 에
`tomsworkers.io` 를 넣은 뒤 Enforce HTTPS 를 켠다. 인증서가 발급될 때까지
길면 한 시간쯤 걸린다.

⚠️ `mybaseballstar` CNAME 은 건드리지 않는다. 같은 GoDaddy 계정에 있지만 다른
사이트를 가리킨다.

## 내용

**회사는 소프트웨어를 만든다.** 마이베이스볼스타는 그중 하나이지 전부가
아니다 — 문구를 고칠 때 회사를 앱 하나로 좁히지 않는다.

적힌 것은 확인된 사실뿐이다. 사업자등록번호와 주소는 일부러 비워 뒀다.
통신판매업도 전자상거래도 하지 않아 전자상거래법상 표시 의무가 없다.
빠뜨린 것이 아니다.

**마이베이스볼스타의 이용약관·개인정보 처리방침과 [시행자] 이름이 어긋나면
안 된다.** 그 문서들의 원본은 `tomsworkers-io/mabas-site` 에 있다.
